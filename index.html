About

I build small, practical data tools: APIs that merge configuration safely, scripts that clean and reorganize archives, and analyses that turn raw CSV files into clear answers.

Projects

12-Factor Config Service

A FastAPI endpoint that merges defaults, YAML, .env, OS environment variables, and CLI overrides in the correct precedence order.

Archive Reorganization

A null-delimited Bash script that flattens nested folders and groups files by category, with full support for spaces and Unicode names.

Sales Data Analysis

A reproducible Python analysis that filters CSV transactions by city and month, calculates revenue, and rounds the result.

Broken JSON Repair

Located and fixed syntax errors in a large JSON configuration export, then validated that every record still parsed correctly.

Code Interpreter API

A FastAPI service that runs Python snippets and uses an LLM to identify the line responsible when the snippet raises an error.
